# 图标清单（icons/）

PWA 安装到手机桌面需要以下图标，请用任意图标生成工具（如 1024×1024 源图）导出：

| 文件 | 尺寸 | 用途 |
|------|------|------|
| `icon-192.png` | 192×192 | 桌面/列表图标 |
| `icon-512.png` | 512×512 | 启动图/高分屏 |
| `icon-maskable-512.png` | 512×512 | 带安全边距的 maskable 图标（Android 自适应图标） |

参考源图可直接复用《600个绝美的诗词成语》现有图标（仓库 `icons/` 目录），或按新产品的视觉重新生成。
