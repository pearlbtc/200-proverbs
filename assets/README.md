# 素材清单（assets/）

PWA 脚手架引用以下图片，首次部署前请替换为你的产品素材：

| 文件 | 用途 | 建议尺寸 |
|------|------|----------|
| `cover.jpg` | 学习库顶部封面图（词库第一栏） | 宽屏 1200×600 左右 |
| `vol1.jpg` ~ `vol8.jpg` | 各分类卷首图（分类库按 CAT_VOL 映射显示） | 竖图 800×1200 左右 |

说明：
- 分类卷首图是**可选**的——`app.js` 里 `CAT_VOL` 没有对应分类时，自动不显示卷首图，不影响功能。
- 文件名必须与 `app.js` 中 `CAT_VOL` 映射一致（如 `"光阴如流水": "vol1.jpg"`）。
- PDF 的封面/卷首图由 `build_book.py` 单独处理（见 `references/md-format.md`），与这里不是同一套，注意区分。
